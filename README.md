# CAPI Không Rò

Trang giới thiệu dịch vụ cài đặt gửi sự kiện chuyển đổi lên Meta Conversions API qua n8n.

Một file `index.html` tự chứa: toàn bộ CSS và JS nằm trong file, không gọi tài nguyên bên ngoài.
Mở trực tiếp bằng trình duyệt cũng chạy được.

## Nội dung

- Triệu chứng thường gặp và giải pháp tương ứng
- Sáu nguyên nhân thất thoát sự kiện khi chỉ dùng pixel trình duyệt
- Sơ đồ kiến trúc đường ống n8n
- Mười một lợi ích khi chuyển sang gửi sự kiện phía máy chủ
- Sơ đồ so sánh mốc "hoàn tất đăng ký" và mốc "mua hàng"
- Bảng so sánh pixel / GTM server-side / CAPI qua n8n
- Hai công cụ tương tác: máy tính thất thoát sự kiện và chấm điểm khớp sự kiện
- Quy trình triển khai, bảng giá, câu hỏi thường gặp

## Sửa nội dung

Giá, thông tin liên hệ và tên thương hiệu nằm trực tiếp trong `index.html`.
Sửa file rồi commit, GitHub Pages tự cập nhật sau khoảng một phút.
